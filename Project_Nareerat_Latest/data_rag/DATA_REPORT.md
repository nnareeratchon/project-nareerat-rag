### 2. คำอธิบายกว้างเกินไป ซ้ำกันข้ามตาราง
คำอธิบายเช่น "ความสัมพันธ์ระหว่างผู้รับผลประโยชน์กับผู้เอาประกันภัย", "คำอธิบายความรับผิดส่วนแรกตามหมวดความคุ้มครอง", "จำนวนวันสูงสุดต่อการรักษาตัวแต่ละครั้ง (วัน)", "จำนวนเงินความรับผิดส่วนแรกตามหมวดความคุ้มครอง (บาท)", "จำนวนเงินผลประโยชน์ที่ระบุเป็นร้อยละ ความรับผิดระหว่างบริษัทและผู้เอาประกันภัย", "จำนวนเงินเอาประกันภัย/จำนวนเงินผลประโยชน์ (บาท)", "จำนวนเงินเอาประกันภัย/จำนวนเงินผลประโยชน์ สูงสุดในแต่ละหมวดความคุ้มครอง ต่อปี (บาท)", "ชื่อความคุ้มครอง", "ตำแหน่ง", "ประเภทเอกสารระบุตัวตน", "รหัสความคุ้มครอง", "รหัสบริษัทประกันชีวิต" ใช้ซ้ำในหลายตาราง ค้นแล้วแยกไม่ออกว่าเป็นของใคร สำเนานี้เพิ่ม `desc_contextual` ที่ต่อท้ายด้วยเจ้าของข้อมูล เช่น "วันเกิด ของผู้เอาประกันภัย"

### 3. การสะกดและรูปแบบข้อความ
ปรับ ํา→ำ, ลบวรรณยุกต์/สระซ้ำ (ข้้อมูล, นำส่่ง), เชิ้อชาติ→เชื้อชาติ, อีเมล์→อีเมล, ลบการขึ้นบรรทัดใหม่กลางคำอธิบาย
