### 1.1.5 ข้อมูลสถานะของกรมธรรม์ (pol_status)

- รหัสคำถาม: IBSLFAQ_POLICY_0005
- หน้า: 14-16
- ฟิลด์: pol_status

**คำอธิบายปัญหา**

กรณีสถานะของกรมธรรม์ (pol_status) มีค่าเป็น NULL หรือมีค่าเป็น 9999
(อื่นๆ) บริษัทควรส่งข้อมูลอย่างไร

**เงื่อนไขการส่งข้อมูล / Business Rule**

โดยมีเงื่อนไขการส่งข้อมูล ดังนี้
• อ้างอิงการส่งข้อมูลจากเอกสารภาคผนวก ก - ตาราง Master data
แบบรายงานเวอร์ชัน ส่วนของ “PolicyStatus” เท่านั้น
• ไม่อนุญาตให้ส่งค่า “9999” หากมีการส่งรหัสดังกล่าวเข้ามา จะแสดง
Error code "1000005" message "The reference data id mismatch"

**ตัวอย่างข้อมูลที่ไม่ถูกต้อง**

• "pol_status": Null
• "pol_status": "9999"

**ตัวอย่างข้อมูลที่ถูกต้อง**

"pol_status": "0100"

**แนวทางแก้ไข / คำชี้แจงสำหรับการปฏิบัติ**

กรณีกรมธรรม์เป็น Expiry
• หาก Expiry หมายถึง กรมธรรม์ที่ครบกำหนดสัญญาความคุ้มครองแล้ว และไม่มีความ
คุ้มครองต่อ แนะนำให้ส่งเป็น pol_status = '0300' : กรมธรรม์ที่ครบสัญญาความ
คุ้มครอง
• หาก Expiry หมายถึง กรมธรรม์ขาดอายุจากการไม่ชำระเบี้ย ไม่ใช่ครบสัญญา แนะนำ
ให้ส่งเป็น pol_status = '0700' : กรมธรรม์ขาดอายุ
กรณีกรมธรรม์เป็น Waiting Approve Add Rider
• สถานะระหว่างกระบวนการพิจารณาเพิ่มสัญญาเพิ่มเติม ซึ่งโดยหลักแล้วไม่ควรถือเป็น
สถานะหลักของกรมธรรม์ เพราะกรมธรรม์หลักยังคงมีสถานะเดิม เช่น In-force /
Renewal / Grace Period เป็นต้น
• pol_status = '0100' : กรมธรรม์ใหม่ หรือ '0200' : กรมธรรม์ปีต่ออายุ

**คำอธิบายปัญหา**

กรณีผู้เอาประกันเพิ่ม-ลด (กรมธรรม์ปีถัดไป) จะต้องนำส่งข้อมูลเข้าระบบ

**แนวทางแก้ไข / คำชี้แจงสำหรับการปฏิบัติ**

กรณีประกันกลุ่มที่มีผู้เอาประกันภัยเพิ่ม-ลด ทางคปภ. จำเป็นจะต้องใช้ข้อมูลส่วนนี้ แต่ใน
เวอร์ชั่น 4.00 ไม่สามารถรองรับข้อมูลการเพิ่ม-ลดได้ โดยทางคปภ. มีเวอร์ชัน 4.01 ที่สามารถ
รองรับกรณีผู้เอาประกันเพิ่ม-ลด (กรมธรรม์ปีถัดไป) ได้แก่เนื่องจากการนำส่งข้อมูล Version
4.01 บนระบบ UAT มีการปรับปรุงโครงสร้างข้อมูลสำหรับผลิตภัณฑ์ประกันกลุ่ม เพื่อรองรับ
การจัดเก็บข้อมูลทุนประกัน รวมถึงกรณีการเข้า และออกของผู้เอาประกันภัย ให้สอดคล้อง
กับข้อกำหนดของสำนักงาน คปภ. ในการเพิ่มฟิลด์สำหรับการนำส่งข้อมูล ดังต่อไปนี้
1. insrd_start_date : วันที่เริ่มต้นของผู้เอาประกันภัย
2. insrd_end_date : วันที่สิ้นสุดของผู้เอาประกันภัย
จึงขอรบกวนทางบริษัทประกัน พิจารณาเกี่ยวกับการระบุข้อมูลดังข้างต้น โดยทางคปภ. จะได้
ปรับเปลี่ยนเพื่อให้บริษัทส่งข้อมูลในเวอร์ชั่น 4.01
ทั้งนี้ ทางคปภ. จะมีการนำส่งคู่มือการส่งข้อมูลเวอร์ชั่น 4.01 ให้บริษัทเพื่อพิจารณาเพิ่มเติม

รายงาน หรือเว็บไซต์ อ้างอิงเอกสารภาคผนวก ข
https://hcode.moph.go.th/dashboard/filter/health_offices
