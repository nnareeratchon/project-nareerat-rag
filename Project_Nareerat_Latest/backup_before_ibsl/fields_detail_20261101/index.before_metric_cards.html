ผลการประเมินประสิทธิภาพระบบ

1. Precision@3 k=3

ความแม่นยำในการค้นคืน

--%

สัดส่วนรายการที่อยู่ในเฉลยจากรายการที่ระบบค้นคืน เทียบกับชุดทดสอบ Ground Truth โดยเฉลี่ยแบบ Macro

2. Recall@3 k=3

ความครอบคลุมคำตอบ

--%

สัดส่วนรายการในเฉลยที่ระบบค้นคืนได้ เทียบกับชุดทดสอบ Ground Truth โดยเฉลี่ยแบบ Macro

3. F1@3 k=3

ค่าเฉลี่ยฮาร์โมนิก (F1-Score)

--%

ค่าเฉลี่ยฮาร์โมนิกของ Precision@3 และ Recall@3 โดยคำนวณ F1 ต่อคำค้นของชุดทดสอบ Ground Truth ก่อน แล้วนำมาเฉลี่ยแบบ Macro

ประวัติผลการทดสอบและประเมินโดยผู้ใช้งาน (สำหรับคัดลอกใส่รายงาน)

แสดงข้อมูลคำค้นหาที่ผ่านการประเมินแล้ว พร้อมค่า User Precision@3 รายคำค้น (นับเฉพาะคำค้นที่ประเมินครบทั้ง 3 รายการแรก)
